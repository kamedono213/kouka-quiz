# 効果・現象クイズ

〇〇効果、〇〇現象、〇〇の法則、〇〇コンプレックス、〇〇症候群、〇〇のパラドックス……。説明を読んで名前を4択で当てるスマホ向けWebアプリ(PWA)。

- 公開URL: https://kamedono213.github.io/kouka-quiz/
- 12分野・236問(認知・判断のくせ/人間関係・社会心理/記憶・学習・教育/お金・行動経済学/ビジネス・マーケティング/医療・健康・からだ/こころ・コンプレックス・症候群/物理・化学・自然現象/生物・進化・環境/数学・論理・パラドックス/社会・政治・まち/IT・テクノロジー・ネット)
- 出題: 分野ごと・全分野それぞれに「ランダム10問」「全問」。まちがえた問題は「にがて復習」にたまり、正解すると消える
- 選択肢は、答えと同じ種類(〇〇効果なら〇〇効果)から選ぶので、語尾で答えが分からない
- 答えたあとに解説(使われ方・おもしろい話)。心理学の効果で、追試で再現できなかったものや議論があるものは、解説にそう書いた

## 作り方
- `data/effects-*.txt` … 問題(`@分野キー|分野名|絵文字` のあと、`名前|説明|解説`)
- `node tools/build-data.js` … `app/data/effects.json`。名前の重複と、説明文に答えの言葉(語尾を除いた部分)が入っていないかを確かめる
- `node tools/make-icons.js` / `node tools/build-pages.js` … アイコン / `docs/`
- `node serve.js docs` … http://localhost:5396 で確認
